Project: Sign Up Page

A Small Registration Form

The goal of this project was to make a registration form for a coding bootcamp. The form also validates input and provides custom error messages.

I decided to use a flexbox layout for this project that switches flex direction from row to column between larger and smaller screen sizes.

In this project, I got to work with regular expressions for form validation. On submission, each input field is tested with regular expressions in an external JavaScript file. Any fields left blank or containing invalid values will have a short error message detailing the issue shown below them, which is triggered by JavaScript code.

Additionally, a box with an error message gets a red border and an error icon that is placed using the background-position CSS property.

The regex implemented is relatively simplistic, but it was fun to get some practice using it.
