Project: Testimonials

Sample Reviews in a Grid View

The goal of this project was to create a grid view of testimonials for a coding bootcamp.

I delved deeper into using CSS frameworks for this project, specifically with Bootstrap. I wanted to focus on becoming more accustomed to frameworks and strengthening my skills with grid, so this project is purely HTML and CSS.

I was able to be a bit more efficient when making the grid for this page. I used a system of nested rows to form the overall layout. The parent row contains 2 columns wherein the first column is the nested grid with the 4 boxes on the left. The second column in the parent row is the tall box on the right.

I used the padding classes of Bootstrap to add even spacing between the boxes. The grid is also responsive to screen resizing thanks to Bootstrap.
