Project: Space Tourism

A Look Into Space Travel

This goal of this project was to create a multi-page website for space tourism. Users are able to view each page in an optimal layout based on their device as well as toggle informational tabs with mouse or keyboard inputs.

This project was completed as part of a course provided by Scrimba and taught by Kevin Powell, so big thanks to them!

For this project, I dove deeper into using the CSS grid to create templates and areas to create the layouts on each page.

I also strengthened my knowledge of ARIA attributes to provide accessible interactive designs, such as with the info tabs.
