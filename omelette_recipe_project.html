Project: Recipe Page

Top Stories at a Glance

The goal of this project was to create a simple recipe page for making an omelette. The page is meant to be semantically appropriate with responsiveness in mind as well.

This project had me explore tables more thoroughly. I played around with the borders and decided to use the last-child pseudo element to ensure the bottom borders only appear between the table items, not on the top or bottom of the table.

I ran into an issue with the recipe list where the Google font of the numbers was being overridden by a default font. To address this, I did some research on CSS counters and tried implementing a list counter to place numbers before each list item using the before pseudo element, which solved the problem.
